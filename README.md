# 💠 Aula 01 - Back-End

## 📚 Sobre o projeto

Este repositório foi criado para armazenar os conteúdos, exemplos e exercícios desenvolvidos durante as primeiras aulas de **Desenvolvimento Back-End**.

O objetivo do projeto é praticar conceitos fundamentais da programação utilizando **JavaScript**, desenvolvendo a lógica de programação e compreendendo estruturas importantes para o desenvolvimento de aplicações no lado do servidor.

---

## 🛠️ Tecnologias utilizadas

* JavaScript
* Node.js
* Visual Studio Code
* Git e GitHub

---

## 📂 Conteúdos abordados

Durante o desenvolvimento dos arquivos presentes neste repositório, foram trabalhados conteúdos como:

* 🔹 Variáveis
* 🔹 Lógica de programação
* 🔹 Operadores matemáticos
* 🔹 Vetores (Arrays)
* 🔹 Objetos
* 🔹 Listas de objetos
* 🔹 Manipulação de duas listas
* 🔹 Estruturas e exercícios em JavaScript
* 🔹 Organização de dados
* 🔹 Conceitos iniciais de Back-End
* 🔹 Estrutura inicial de servidor

## 💻 Como executar o projeto

Para executar os arquivos JavaScript, é necessário ter o **Node.js** instalado no computador.

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/giovanaremorini-dotcom/Aula01_back_end.git
```

### 2️⃣ Acesse a pasta do projeto

```bash
cd Aula01_back_end
```

### 3️⃣ Execute um arquivo JavaScript

Por exemplo:

```bash
node index.js
```

Ou execute outro arquivo desejado:

```bash
node vetores.js
```

> ⚠️ O comando deve ser executado dentro da pasta onde o arquivo está localizado.
